# Wenli Wu — Academic Homepage

Source code for [Wenli Wu's academic homepage](https://adios-cowboy.github.io/).

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000/`.

## Editing content

- Profile and biography: `_data/profile.yml`
- Navigation and homepage display: `_data/navigation.yml`, `_data/display.yml`
- Publications: `_publications/`
- News: `_news/`
- Projects and activities: `projects.html`, `activities.html`
- Images: `assets/images/`

The site is based on Shitong Luo's [academic-homepage](https://github.com/luost26/academic-homepage) template and retains its MIT license.
